Original View Transition Logic in Navbar.jsx:
const handleToggleTheme = (e) => {
  if (isTransitioningRef.current) return;
  const nextTheme = theme === 'light' ? 'dark' : 'light';
  if (!document.startViewTransition || window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
    setTheme(nextTheme);
    return;
  }
  isTransitioningRef.current = true;
  const rect = e.currentTarget.getBoundingClientRect();
  const x = rect.left + rect.width / 2;
  const y = rect.top + rect.height / 2;
  const endRadius = Math.hypot(Math.max(x, window.innerWidth - x), Math.max(y, window.innerHeight - y));
  document.documentElement.classList.add('theme-transitioning');
  const transition = document.startViewTransition(() => {
    flushSync(() => { setTheme(nextTheme); document.documentElement.setAttribute('data-theme', nextTheme); });
  });
  transition.ready.then(() => {
    const wave = document.createElement('div');
    wave.className = 'theme-pulse-wave';
    wave.style.left = `${x}px`; wave.style.top = `${y}px`;
    wave.style.setProperty('--pulse-max-size', `${endRadius * 2}px`);
    document.body.appendChild(wave);
    setTimeout(() => wave.remove(), 650);
    document.documentElement.animate({ clipPath: [`circle(0px at ${x}px ${y}px)`, `circle(${endRadius}px at ${x}px ${y}px)`] }, { duration: 550, easing: 'cubic-bezier(0.2, 0, 0, 1)', pseudoElement: '::view-transition-new(root)' }).finished.finally(() => {
      document.documentElement.classList.remove('theme-transitioning');
      isTransitioningRef.current = false;
    });
  });
};
--------------------------------------------------------------------------------
Static Modification Made:
Theme switching is executed as an immediate, static state switch:
setTheme(nextTheme) directly without View Transitions or .theme-pulse-wave.
In src/styles/main.css, .theme-pulse-wave is set to display: none !important.

8. INTENTIONALLY PRESERVED FUNCTIONAL ANIMATIONS
================================================================================
In accordance with engineering guidelines, the following functional animations
have NOT been removed, as they communicate active user operations or network state:

1. Voice Dictation Active Recording Pulse:
   - File: src/styles/hero.css (.pulse-dot, @keyframes pulse)
   - Function: Communicates to the user that the microphone is actively listening.

2. Authentication Form Network Loading Spinner:
   - File: src/styles/auth.css (.auth-spinner, @keyframes authSpin)
   - Function: Communicates active network request during "Signing In...", "Signing Up...",
     and "Updating Password...".

3. Newsletter Subscription Network Spinner:
   - File: src/styles/newsletter.css (.animate-spin, @keyframes spin)
   - Function: Communicates in-flight API submission.

4. Usability Hover/Focus Interactions:
   - Button hover color changes, border-color shifts, and accessibility
     focus-visible outlines are preserved for functional usability.
